API

Static data endpoints, version 1, under data/v1/. Live functions: /api/health, /api/reveals, /api/preorders, and the daily Radar cron at /api/cron/radar.

  • index — data/v1/index.json · Self-describing manifest: every endpoint with path, description, schema URLs, ISO-8601 UTC updated timestamp, record counts, and deprecation notes. Start here.
  • stats — data/v1/stats.json · Archive totals: wave/figure counts, year range, BAF/exclusive/variant tallies, per-year and per-manufacturer breakdowns. Cheapest entry point for overview questions.
  • waves — data/v1/waves.json · One summary per wave: id, year, manufacturer, series, BAF name (nullable), story source (nullable), figure count.
  • figures — data/v1/figures.json · Flat list of every figure with wave context and stable ids (wave and figure name). Filter client-side by year, manufacturer, waveId, exclusive, variant, bafPiece.
  • encyclopedia — data/v1/encyclopedia.json · Collector encyclopedia: line history, packaging evolution, variant/chase/exclusive taxonomy, hall of fame (with reissue-radar flags), grading guide, transparent price methodology, bootleg-spotting guide, resources directory. Editorial knowledge, not catalog data.
  • preorders — data/v1/preorders.json · Researched upcoming releases: status (preorder/revealed/available), exact preorderDate (YYYY-MM-DD, null when unreported, never invented), releaseWindow, announced MSRP (never a market price), retailer search patterns, hobby-press sources.
  • characters — data/v1/characters.json · Character guides: every character with a dedicated page, slug, display name, release count, first/last year, and the page path. Join to figures.json by character name for shelf audits.
  • timeline — data/v1/timeline.json · The Legends Timeline: year-by-year line history 2002-2026, era, headline, summary, sourced milestones, packaging notes, per-year wave records (ids link into the archive), and spotlight figure ids.
  • rarity — data/v1/rarity.json · The Rarity Guide: chase vs variant vs exclusive vs limited, tier definitions with sourced examples (real figure ids), how-to-spot notes, value notes (reported prices only), archive signal counts, and the quest-achievement mapping. Generated by scripts/build_rarity.py.
  • price-signals — data/v1/price-signals.json · Reported market price signals for the Price Watch: curated, sourced sold-band / sold-avg / listing / claimed prices already published on the Chronicle (encyclopedia, market briefing), reported ranges, not live prices; the Chronicle publishes no price index.
  • launch-curves — data/v1/launch-curves.json · The Launch Curve: real sold-price timelines for newly launched figures, every point a reported eBay sold/presale from a named hobby tracker, with sellout event markers and MSRP. Documents the sellout → spike → cool → retail pattern; reported timelines, not predictions. Generated by scripts/build_launch.py.
  • drop-week — data/v1/drop-week.json · Drop Week Command Center: the Oct 14 → Nov 1 drop sequence + Nov 20 made-to-order deadline, confirmed drop windows, lineups with researched accessory notes, announced prices, ship windows, scarcity/price/KO intel, and rumor watch (flagged uncertain). Editorial payload generated by scripts/build_dropweek.py from data/drop-week.json.
  • radar-candidates — data/v1/radar-candidates.json · Hand-maintained reissue-radar research feed: newly spotted news items (title, URL, source, detection time). Research notes, not a generated snapshot.
  • radar-seen — data/v1/radar-seen.json · Hand-maintained dedupe list of radar URLs already processed. Array of URL strings.
  • compare — data/v1/compare.json · VS-mode figure profiles: one for every figure in the census, each with a stable deep link (waves/<waveId>.html#fig-<slug>), a shareable compare link (compare.html?a=<id>), a rarity tier cross-reference, price signals (reported ranges, never live prices), a knock-off watch note, and upgrade paths (documented other releases of the same character). Powers the Figure Compare page; derived from committed data by scripts/compare_lib.py.
  • year-review — data/v1/year-review.json · 2026: The State of Legends, the year-in-review: scored Top-10 2026 releases (transparent distinction criteria), 2026 archive stats, reported-price movement math (reported solds only, never an index), best-value picks from announced MSRPs, KO watch, rarity highlights, and honest data gaps. Generated by scripts/build_review.py.
  • quest-market — data/v1/quest-market.json · Quest-market intel: the 2026 Market Briefing's published numbers as machine-readable data for the Grail Quest, 2026 MSRP tiers (standard $27.99, deluxe $34.99–$46.99, Miles mask $139.99), the dead-modern-chase era (white Doom $115–$200 reported band), the reissue program's sellout → spike → reissue → collapse pattern, KO watch, and the Doomsday Wave 1 launch-curve cooling. Reported listings/solds only, never an index. Generated by scripts/build_quest_market.py from data/quest-market.json.

Agent procedures

Start at the manifest endpoint above. Read the schema beside each endpoint before parsing it. Counts in the manifest are the census: 1,939 figures, 167 waves, 66 characters.

Skills

The skills manifest is published with the API documentation in this repository (skills/ and data/v1/index.json). Procedures that change data run through the generator, scripts/build_r23.py, and the result is verified against the census before it is committed.
