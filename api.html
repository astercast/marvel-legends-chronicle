The API

Versioned static JSON for agents and tools. Stable ids, explicit years, and provenance notes. Start at api/v1/index.json; full reference lives in API.md. For the agentic playbooks (220 skills incl. 8 agent playbooks) see the skills library and the agents page.

Archive № api-v1

Endpoints

api/v1/index.json

Self-describing manifest: every endpoint with schema URLs, ISO-8601 UTC updated, record counts, deprecation notes.

api/v1/stats.json

Totals, per-year and per-manufacturer counts, BAF/exclusive/variant tallies.

api/v1/waves.json

158 waves with series, year, manufacturer, BAF, and figure counts.

api/v1/figures.json

Flat list of all 1,904 figures with wave context and stable ids.

api/v1/encyclopedia.json

History, packaging evolution, variant/chase taxonomy, hall of fame (with reissue radar), grading guide, price methodology, bootleg guide, resources. New claims carry source + confidence.

api/v1/preorders.json

22 researched upcoming releases (waves 12 + 20 + 24 + 28): status, exact pre-order dates where reported, release windows, announced MSRP, source links, window-result honesty field. Powers the pre-order tracker and release calendar.

api/v1/characters.json

66 character guides: slug, name, release count, first/last year, page path.

api/v1/timeline.json

The Legends Timeline: 25 year records (2002–2026) — sourced milestones, packaging eras, per-year waves (real archive ids), spotlight figures. Item schema timeline-year.json.

api/v1/rarity.json

The Rarity Guide: 9 tiers (chase, running-change, deco, unmasked, convention, retailer, Pulse/Fan Channel, HasLab, made-to-order) — sourced examples (real figure ids), how-to-spot, value notes (reported prices only), archive counts, quest mapping. Item schema rarity-tier.json.

api/v1/price-signals.json

Reported market price signals for the Price Watch: curated, sourced sold-band / sold-avg / listing / claimed prices already published on the Chronicle (encyclopedia, market briefing) — reported ranges, not live prices; the Chronicle publishes no price index. Item schema price-signal.json.

api/v1/launch-curves.json

api/v1/drop-week.json

Drop Week Command Center: the Oct 14 → Nov 1 drop sequence + Nov 20 made-to-order deadline — confirmed windows, lineups with researched accessory notes, announced prices, ship windows, scarcity/price/KO intel, rumor watch flagged uncertain.

The Launch Curve: real sold-price timelines for newly launched figures — every point a reported eBay sold/presale from a named hobby tracker, with sellout event markers and MSRP. Documents the sellout → spike → cool → retail pattern; reported timelines, not predictions. Item schema launch-curve.json.

api/v1/compare.json

VS-mode figure profiles (1,904): stable deepLink (waves/<waveId>.html#fig-<slug>), shareable compareUrl, rarity tier cross-ref, priceSignals (reported ranges, never live), koWatch note, upgradePaths (documented other releases of the same character). Powers the Figure Compare page. Item schema compare-profile.json.

api/v1/year-review.json

2026: The State of Legends — scored Top-10 2026 releases (transparent distinction criteria), 2026 archive stats, reported-price movement math (reported solds only, never an index), best-value picks, KO watch, rarity highlights, honest gaps. Powers the 2026 year-in-review page. Item schema year-review-item.json.

api/v1/radar-*.json

Hand-maintained reissue-radar research feed (radar-candidates.json) + processed-URL dedupe list (radar-seen.json).

api/v1/schema/

JSON Schema (draft-07) for every endpoint — plus per-record item schemas.

Live server API

/api/health

Service health (marvel-radar): status ok/degraded, function roster, per-file freshness with 24h SLA verdicts, boolean checks. Never 5xx.

/api/reveals

Latest reveals: ?since= (ISO date, default 30d) + ?limit= (default 50, 1–200). Press detections grouped by story — status rumor until 2+ sources confirm, wave/figures null until researched, price_tbd always true. Static twin: api/v1/radar-candidates.json.

/api/preorders

Upcoming pre-order dates: id, name, status, goes_live_at (midnight UTC — the file carries dates, never times), retailers, price or price_tbd, release window, sources. Static twin: api/v1/preorders.json.

/api/cron/radar

Daily (15:00 UTC) collector-press poll — cron-only, CRON_SECRET bearer required. Polls press, dedupes, appends candidates, commits on change.

Every live endpoint returns the shared envelope (ok / data / meta with request_id; errors carry error.code). Schema: api/v1/schema/envelope.json. Edge-cached 10 minutes. The frontend tries the live endpoint first with a 7s timeout and falls back to the static twin — the live / cached · updated HH:MM badge next to each widget says which one you're seeing.

Try the API

Pick an endpoint and fetch it live — the same JSON any agent consumes. Output is truncated at 2,000 lines; the full payload is one click away via the endpoint cards above. The endpoint list loads from api/v1/index.json itself.

Choose an endpoint and press Fetch.

If fetching fails with a network error, this page is being opened as a file — serve the site over HTTP (e.g. python3 -m http.server) and try again. Agents: the proven, tested versions of the three core workflows live in AGENT.md.

Stable ids

Figure ids are <waveId>::<figureName>, e.g. toybiz-2002-series-1::Hulk. Wave ids are kebab-case slugs like hasbro-2012-return-1. Ids are stable across releases of the dataset; new figures get new ids, never recycled ones.

Unknown or disputed values are explicit null with a notes field — never invented. Some BAF pieces and within-year ordering are flagged unverified in the source data.
