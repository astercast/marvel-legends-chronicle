# Authenticate a listing end-to-end

## Use when

Before buying any figure above impulse-buy price.

## Inputs

- Listing URL or photos
- Seller profile

## Procedure

1. Run all six bootleg checklists (packaging, paint, joints, targets, listings, price-logic).
2. Check the seller: feedback history, other listings, stock-photo vs real-photo.
3. Price logic: if it's 40%+ under 90-day solds, assume bootleg until proven otherwise.
4. For grails: demand provenance, where did they get it, when, any receipts.
5. When in doubt, pass. Another listing always comes.

## Worked example

A $40 'SDCC exclusive' with stock photos and 3 feedback: three fails, pass.
