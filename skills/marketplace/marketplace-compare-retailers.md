# Compare retailers

## Use when

Deciding where to hunt.

## Inputs

- Figure
- Urgency

## Procedure

1. New releases: retail first (Hasbro Pulse, BBTS, EE) — aftermarket is for misses.
2. Aftermarket: eBay (selection), Mercari (deals), Whatnot (live, risky).
3. Community: r/MarvelLegends and Facebook groups — best prices, slowest.
4. Factor shipping: a $5 deal with $12 shipping is a $17 figure.

## Worked example

Missed a wave? BBTS pile-of-loot first, then eBay solds for the gap figures.

## Pitfalls

- Whatnot hype bidding — set your max before the stream starts.
