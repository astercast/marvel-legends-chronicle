# Hunt chase variants in the wild

## Use when

Active retail hunts.

## Inputs

- Case ratios
- Store stock patterns

## Procedure

1. See variants-chase-hunting for pricing; this is the field tactics.
2. Feel the weight? No, check the assortment code on the box.
3. Befriend stock staff; ask about truck days.
4. Don't be the person who tears cases open in the aisle.

## Worked example

Assortment code check found the chase without opening a single box.

## Pitfalls

- Scalper behavior, the community remembers.
