# Complete the Warlock (New Mutants) Build-A-Figure

## Use when

You want to build the Warlock (New Mutants) BAF from the 2017 Warlock Wave wave. 6 figures carry pieces.

## Inputs

- Your current figure inventory
- The BAF piece you still need

## Procedure

1. The BAF: **Warlock (New Mutants)** (2017, Warlock Wave).
2. Checklist, buy the figure, keep the piece:
  - [ ] Colossus → Head and alternate saw hand
  - [ ] Cyclops → Left leg
  - [ ] Dazzler → Left arm
  - [ ] Polaris → Right leg
  - [ ] Shatterstar → Right arm
  - [ ] Sunfire → Torso
3. Prioritize: figures you want anyway first, then cheapest piece-carriers.
4. Verify each piece against the BAF's assembly (some waves split one piece across variants).
5. Keep boxes until the BAF is complete, piece claims need proof.

## Worked example

Missing the Warlock (New Mutants) torso? Find which figure above carries it, check sold listings for the cheapest loose complete figure.
