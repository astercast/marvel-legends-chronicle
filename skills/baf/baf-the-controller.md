# Complete the The Controller Build-A-Figure

## Use when

You want to build the The Controller BAF from the 2022 The Controller Wave wave. 6 figures carry pieces.

## Inputs

- Your current figure inventory
- The BAF piece you still need

## Procedure

1. The BAF: **The Controller** (2022, The Controller Wave).
2. Checklist, buy the figure, keep the piece:
  - [ ] Blue Marvel → Left leg
  - [ ] Madame Hydra → Right leg
  - [ ] Quake → Left arm and alternate hand
  - [ ] Speedball → Torso
  - [ ] Thor → Head
  - [ ] U.S. Agent → Left arm and alternate hand
3. Prioritize: figures you want anyway first, then cheapest piece-carriers.
4. Verify each piece against the BAF's assembly (some waves split one piece across variants).
5. Keep boxes until the BAF is complete, piece claims need proof.

## Worked example

Missing the The Controller torso? Find which figure above carries it, check sold listings for the cheapest loose complete figure.

## Data references

- `data/figures.json`

## Pitfalls

- Buying a figure for the piece, then discovering the variant doesn't include it, check bafPiece notes.
- Bootleg BAF pieces don't fit right, authenticate the figures first.
