# Complete the Sandman (Spider-Man 3) Build-A-Figure

## Use when

You want to build the Sandman (Spider-Man 3) BAF from the 2007 Sandman (Spider-Man 3) Wave wave. 7 figures carry pieces.

## Inputs

- Your current figure inventory
- The BAF piece you still need

## Procedure

1. The BAF: **Sandman (Spider-Man 3)** (2007, Sandman (Spider-Man 3) Wave).
2. Checklist, buy the figure, keep the piece:
  - [ ] Doctor Octopus → Right arm
  - [ ] Green Goblin → Leg
  - [ ] Mary Jane Watson → Torso
  - [ ] New Goblin (Harry Osborn) → Head
  - [ ] Sandman → Left foot
  - [ ] Spider-Man → Leg, Right foot
  - [ ] Venom → Left arm
3. Prioritize: figures you want anyway first, then cheapest piece-carriers.
4. Verify each piece against the BAF's assembly (some waves split one piece across variants).
5. Keep boxes until the BAF is complete, piece claims need proof.

## Worked example

Missing the Sandman (Spider-Man 3) torso? Find which figure above carries it, check sold listings for the cheapest loose complete figure.
