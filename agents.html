For agents

Agents

The full agentic surface of the Chronicle: the versioned JSON API, llms.txt, the 219-skill playbook library, and the data-freshness rules. Skills are the primary interface for doing work; the JSON endpoints are the data layer.

How an agent should work here

  1. Read llms.txt — the one-page index of what this archive is and where everything lives.
  2. Open api/v1/index.json — the manifest: version, observation date, endpoint map, and the for_agents pointer.
  3. Read skills/index.json and load the skill whose task matches the user's request — each skill is a markdown playbook: Use when, Inputs, Procedure, Worked example, API/Data references, Pitfalls.
  4. Fetch only the API endpoints the skill names. stats.json is the cheapest overview; figures.json is the heavy one.
  5. Answer with the archive's honesty rules: unknown = explicit null, prices = reported/user-logged only (never a market index), single-source claims flagged. Full reference lives in The API and API.md.

API endpoints

Static versioned JSON under api/v1/ — no auth, no rate limits. Documented in full at api.html / API.md.

api/v1/index.json

Self-describing manifest: every endpoint with schema URLs, ISO-8601 UTC updated, record counts, deprecation notes.

api/v1/stats.json

Totals, per-year and per-manufacturer counts, BAF/exclusive/variant tallies.

api/v1/waves.json

158 waves with series, year, manufacturer, BAF, and figure counts.

api/v1/figures.json

Flat list of all 1,904 figures with wave context and stable ids.

api/v1/encyclopedia.json

History, packaging evolution, variant/chase taxonomy, hall of fame (with reissue radar), grading guide, price methodology, bootleg guide, resources.

api/v1/preorders.json

20 researched upcoming releases: status, exact pre-order dates where reported, release windows, announced MSRP, source links.

api/v1/characters.json

66 character guides: slug, name, release count, first/last year, page path.

api/v1/radar-*.json

Hand-maintained reissue-radar research feed + processed-URL dedupe list.

api/v1/schema/

JSON Schema (draft-07) for every endpoint — plus per-record item schemas.

The skills directory

219 task procedures in skills/, indexed by skills/index.json — rebuilt with python3 scripts/build_skills.py (generator; new hand-authored skills go in its HAND list). Categories: agents (7), baf (101), characters (46), grails (24), bootleg (8), collection (5), community (4), eras (5), hunts (11), marketplace (4), variants (4). The agents category is the seven cross-cutting playbooks — they use an API references section pointing at api/v1 endpoints; every other category uses Data references pointing at data/*.json.

  • preorder-hunter — find what's coming, when, and where (drives the pre-order tracker + radar).
  • market-brief-reader — read the market briefing honestly: reported solds only, never an index.
  • ko-spotter — KO risk verdicts from market intel + auth-wizard logic.
  • grail-evaluator — assess a grail candidate: rarity signals, variant/chase data, what the archive does and doesn't know.
  • baf-strategist — cheapest-first BAF completion from owned/wanted state.
  • collection-auditor — shelf summary: coverage gaps, era splits, next acquisitions.
  • api-client — call the API from code: endpoints, schemas, example fetches (companion to AGENT.md).

Data freshness

The whole dataset was last observed 2026-10-11 (every endpoint carries its observed date). Agent rules for freshness:

  • Pre-order dates: preorderDate is exact (YYYY-MM-DD) only when hobby press reported one; null means unreported — never fill it in. releaseWindow ("Fall 2026") is a season, not a date.
  • Radar (radar.html): research notes on newly spotted releases — status pills (revealed / pre-order / available) are the freshest signal; the tracker is the canonical schedule.
  • Prices: there is no price index. The market briefing quotes reported eBay solds; the journal/pricing tools on the site use the user's own logged sales. Frame every number as reported or user-logged.
  • Single-source flags: hall-of-fame entries with verified: false come from one or tabloid source — present as lore, not data.

Worked agent workflows

The full agent guide is AGENT.md — base pattern, example requests, the interactive tools' data shapes, and these three workflows as tested code (tests/test-api-workflows.js runs them against the real api/v1 JSON).

"What should I pre-order this month?"

  1. Load skill preorder-hunter.
  2. Fetch api/v1/preorders.json; sort by status then date.
  3. Exact-date items first: e.g. the X-Men '97 retro wave pre-order opens 2026-10-21 — actionable. Mini Comics Wave 3 (opened 2026-10-06) — available now via retailer search.
  4. revealed items with only a season (Avengers: Doomsday, Fall 2026) go on the watchlist, never the buy list.
  5. Report what you know vs. don't; cite sources links for every claim.

"Is this eBay listing a KO risk?"

  1. Load skill ko-spotter.
  2. Fetch api/v1/encyclopedia.json → bootlegGuide; run all six checklists (packaging, paint, joints, targets, listings, price-logic).
  3. Apply price logic: 40%+ under 90-day reported solds = assume bootleg until proven otherwise; watch the Shopee fraud zone (KOs priced like genuine).
  4. Apply photo tells: stock vs real photos, peg differences, joint gaps (e.g. KO Carnage's silver eyes).
  5. Verdict with fails listed; when in doubt, recommend passing — never pressure-buy.

"Audit my X-Men shelf"

  1. Load skill collection-auditor.
  2. Fetch api/v1/stats.json + api/v1/figures.json; take the user's owned/wanted state as input.
  3. Near-complete wins first: waves past 50%, BAFs missing 1–2 pieces, characters nearly complete.
  4. Spot era gaps (e.g. all-modern shelf with zero Toy Biz); name the gap and the cheapest representative fix.
  5. Deliver counts, era splits, top 3 gaps, top 3 next pickups — plain sentences, no invented prices.
