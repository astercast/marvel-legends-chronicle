# Marvel Legends Chronicle fonts: provenance

All faces are self-hosted from assets/fonts/. No page makes a remote
font request.

- Instrument Sans (variable, weight 400-700, width 75-100), latin
  subset woff2: instrument-sans-latin-var.woff2. Instrument Sans is
  licensed under the SIL Open Font License 1.1. Downloaded 2026-10-24
  from Google Fonts (instrumentsans v4) for the Round 2 consult build,
  replacing the fonts.googleapis.com stylesheet request on every page.

The older faces in this folder (Cinzel, Newsreader) are kept for the
record; the current design (legend.css) sets type in Instrument Sans.
